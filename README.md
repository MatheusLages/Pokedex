# Pokédex

Uma aplicação web para explorar uma seleção de 32 Pokémon da região de Kanto. O projeto apresenta um catálogo com imagens, nomes, números e tipos de cada Pokémon, em uma interface responsiva.

É possível pesquisar Pokémon por nome ou número, filtrar por tipo, ordenar o catálogo e visualizar detalhes como descrição, altura e peso. A aplicação também permite marcar Pokémon como favoritos e consultar essa seleção posteriormente.

O projeto foi desenvolvido com HTML, CSS, JavaScript e Bootstrap, utilizando JSON Server para disponibilizar os dados e salvar os favoritos.
